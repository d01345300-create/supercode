Данная программа сделана ИИ для вайбкодинга.
Данная программа может дать руки даже самой слабой нейросети.

Как установить:
1. Поместите `supercode` в `/home/(имя пользователя)/bin`.
2. Выдайте права на выполнение.
3. Готово.

Управление:
- `F6` — вкл/выкл выполнение команд в цитатах (для слабых моделей, когда не слушают системный промпт)
- `Ctrl+P` — команды
- `Tab` — режимы
- и др. (видно в программе)
